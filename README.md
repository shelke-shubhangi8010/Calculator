# Calculator Web Application

## 📌 Project Description
This is a simple and responsive calculator built using HTML, CSS, and JavaScript.

The calculator performs basic arithmetic operations with a clean and user-friendly interface.

## 🛠 Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear (AC) button
- Responsive design

## ▶ How to Run
1. Download or clone the repository
2. Open index.html in any web browser

## 📂 Project Structure
- index.html
- style.css
- script.js
